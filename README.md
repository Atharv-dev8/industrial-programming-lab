# Industrial Programming Lab

> A structured collection of programming implementations focused on problem solving, data structures, systems programming, Java development, object-oriented design, networking, multithreading, and low-level design.

This repository contains practical implementations developed to strengthen core programming and software engineering fundamentals. The codebase spans foundational algorithmic logic, low-level memory control, concurrent systems, and object-oriented system design.

## Repository Structure

The repository is organized conceptually into 16 learning modules:

```text
industrial-programming-lab/
├── 01-logic-building/                    # Decision making, iterative control, mathematical logic
├── 02-arrays-and-matrices/               # Array operations, traversals, matrix manipulation
├── 03-strings/                           # Character arrays, string algorithms, parsing, tokenization
├── 04-bit-manipulation/                  # Bitwise operations, bit masks, binary arithmetic
├── 05-memory-management/                 # Pointers, dynamic memory allocation, memory layouts
├── 06-structures-and-generic-programming/# C structs, unions, function pointers, C++ templates
├── 07-recursion/                         # Recursive algorithms, call-stack mechanics, backtracking
├── 08-data-structure-implementation/     # Linked lists, stacks, queues, trees, custom data structures
├── 09-searching-and-sorting/             # Linear/binary search, sorting algorithm implementations
├── 10-core-java/                         # Classes, objects, inheritance, interfaces, exception handling
├── 11-java-collections/                  # Lists, sets, maps, queues, iterators, comparators
├── 12-file-and-system-programming/       # File streams, binary I/O, serialization, system utilities
├── 13-network-programming/               # Socket programming, TCP/UDP client-server communication
├── 14-multithreading/                    # Threads, synchronization, locks, concurrency utilities
├── 15-object-oriented-design/            # OOAD, SOLID principles, class responsibility modeling
├── 16-design-patterns-and-lld/           # Design patterns, system modeling, low-level design
```

## Featured Technical Work

Key implementation areas explored in this repository include:

- **Custom Data Structure Implementations**: Hand-crafted implementations of linked lists, stacks, queues, and tree structures without relying on standard library abstractions.
- **Low-Level Memory Management**: Manual memory allocation, pointer mechanics, and resource lifecycle management in C.
- **Concurrent & Networked Systems**: Thread synchronization, critical section management, race condition prevention, and socket-based TCP client-server architectures.
- **Object-Oriented & Low-Level Design**: Modular class modeling, SOLID-compliant abstractions, and standard Gang of Four (GoF) design patterns applied to software components.

*Note: Standalone software projects (such as Custom Virtual File System and Parking Lot Automation System) are maintained in separate repositories and will be referenced directly as their repositories are published.*

## Approach

The repository follows a systematic progression:

$$\text{Fundamentals} \longrightarrow \text{Implementation} \longrightarrow \text{Data Structures} \longrightarrow \text{Systems Programming} \longrightarrow \text{Java} \longrightarrow \text{Concurrency \& Networking} \longrightarrow \text{OOP Design} \longrightarrow \text{Design Patterns \& LLD}$$

The emphasis is on writing implementations from first principles, understanding underlying system and memory mechanics, and gradually transitioning from procedural problem-solving toward scalable software architecture and low-level design.
